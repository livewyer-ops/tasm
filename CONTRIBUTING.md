# Contributing

Branch from `main` and run the [checks](docs/development.md) for your change. Keep the [BBC TAMS 8.2 contract](contracts/tams/) intact. Include the source and redistribution terms for new third-party files.

In your pull request, describe the change, its effect on existing stores and how you tested it. Contributions use the project's [Apache-2.0 licence](LICENSE).
