Source
A source groups related media, such as video and audio from the same recording.
Flow
One representation of a source, ordered by time.
Segment
A reference to a stored media object over a time range in a flow.
Object
Stored media bytes. Segments can reuse an object at different offsets.

Welcome to Playpen
Use TAMS Playpen to experiment with arranging video and audio by time. Start with the supplied samples or import your own clips, try insertions and offsets, and explore how an arrangement can reuse stored media.
Your edits are kept as a local draft. Save prepares the arrangement for playback and inspection through the TAMS API. Your media and edits stay in this browser.
