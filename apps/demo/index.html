Terms
Source: the identity of a piece of content, such as a recording.
Flow: a representation of that content with particular media properties and a timeline.
Segment: a record connecting a time range on a flow to a stored media object.
Media object: the stored media data that a segment refers to. Multiple flows can use the same object.
API: the interface an application uses to ask TAMS to store, find and retrieve media.
In this demo, a collection flow groups the video flows. Publishing makes a completed flow available through that collection.

Welcome to TAMS in Practice
TAMS (Time Addressable Media Store), developed by BBC R&D, lets applications store and retrieve media by time via an API.
In this demo, you’ll store a short video, play a chosen time range and create an excerpt without making another copy of the media. Along the way, you’ll learn what sources, flows and segments mean in TAMS, and see the API calls behind each action.
The demo runs in your browser using TASM, a TAMS 8.2 implementation developed at LiveWyer and compiled to WebAssembly.
