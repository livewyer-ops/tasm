# Guided Demo

Open the [Demo](https://demo.tams.lwy.sh/) and choose **Start demo**. Follow the eight steps to create a source, add a video flow, upload media and play a time range.

Select a timeline segment to see its object ID in **Media objects** and the corresponding requests in **Under the hood**. **Check storage** reads each object's size with an HTTP HEAD request. Once the segments are published, use the range menu to play the whole example or its first or last two seconds.

**Restart walkthrough** reuses the saved example. **Reset Demo** deletes the Demo's local media and metadata. Close other Demo tabs before resetting.
